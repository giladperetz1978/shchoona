# החיים בשכונה

משחק עיר תלת־ממדית בעברית: הולכים ברחובות, נכנסים לעסקים, מדברים עם תושבים ומתחרים על כסף, השכלה, קריירה ואיכות חיים. אפשר לשחק מקומית מול דני הממוחשב, או בחדר פרטי לשני שחקנים דרך שרת המשחק. בהשראת מבנה השבועות של **Jones in the Fast Lane**, עם קוד וסביבה מקוריים; ללא נכסים של Sierra. תושבי העיר הם יצורים צבעוניים שעוצבו לפי תמונת הייחוס שסופקה, לצד עיצובים נוספים.

## הפעלה

נדרש Node.js 22 ומעלה. מתקינים פעם אחת את Three.js (ברישיון MIT); אין שלב בנייה.

```powershell
npm ci
npm start
```

נכנסים לכתובת http://127.0.0.1:4173. השרת מאזין למחשב המקומי בלבד. כדי להשתמש בפורט אחר:

```powershell
$env:PORT = "4174"
npm start
```

```powershell
npm test
npm run check
```

## המשחק באינטרנט ופרסום עדכונים

כתובת המשחק: **https://giladperetz1978.github.io/shchoona/**

המאגר: https://github.com/giladperetz1978/shchoona

התהליך [deploy-pages.yml](.github/workflows/deploy-pages.yml) מופעל בכל פוש לענף `main`, או ידנית מלשונית Actions. הוא מתקין תלויות נעולות, מריץ בדיקות ובדיקת תחביר עם Node.js 22 ואורז את קובצי המשחק יחד עם Three.js והרישיון שלו ל־GitHub Pages. המשחק המקומי באתר אינו דורש שרת Node; **חדרי רשת לא פועלים ב־GitHub Pages לבדו**. בהגדרות Pages, מקור הפרסום צריך להישאר **GitHub Actions**.

הפניות למשאבים הן יחסיות, כך שהמשחק עובד גם תחת נתיב הפרויקט `/shchoona/`. קובצי הבדיקות, שרת הפיתוח והתיעוד נשמרים במאגר אך אינם נכללים באתר המפורסם.

השמירה המקומית ב־`localhost` אינה עוברת אוטומטית לכתובת GitHub Pages: לכל כתובת אתר אחסון דפדפן נפרד. הפרסום אינו מוחק את השמירה המקומית.

## מה כבר אפשר לעשות

- עיר Three.js בגוף שלישי: עשרה יעדים, בניינים עם כניסות מסומנות, חללים פנימיים מרוהטים, הולכי רגל, תנועה ברחוב, צללים ושילוט בעברית.
- הליכה בחיצים או WASD, ריצה עם Shift, גרירה לסיבוב המצלמה וגלילה לזום. Q/R מסובבים גם במקלדת. לחיצה על יעד במפת הניווט מתחילה הליכה אוטומטית; תנועה ידנית מבטלת אותה.
- ליד כניסה או דמות: E או כפתור הפעולה שעל המסך. אפשר לנוע בתוך המבנה, לשוחח, לבצע פעולות ולצאת דרך הדלת.
- לכל פעולת משחק יש ביצוע חזותי: הדמות ניגשת לעמדה, משתמשת בחפצים ומבצעת תנועות מתאימות. משמרת בקפה כוללת מכונה והגשה ללקוח; קפה עם חברים כולל ישיבה ושתייה סביב שולחן. יש גם בישול, אכילה, שינה, מחשב, לימודים, קניות, בנק, אימון ומעבר דירה. אותן סצנות מופיעות בתור היריב.
- עשר דמויות עם שיחות בחירה, תגובות וזיכרון שבועי. כתוביות תמיד זמינות; הקראה אופציונלית רק באמצעות קול עברי **מקומי** המותקן בדפדפן. אין דיבוב מוקלט או שירות קול חיצוני.
- מרוץ מול יריב שמשתמש בחוקי המשחק עצמם. אחרי סיכום השבוע צופים בתור שלו בעיר ובמבנים, עם עצירה, פעולה הבאה והאצה. אפשר לצפות שוב בלי לשנות את התוצאה.
- מיני־משחק בבית הקפה: מרכיבים משקה לפי הזמנה, מגישים ומקבלים שכר וטיפ על דיוק.
- עבודה בבית קפה, בתפעול ובתוכנה; התקדמות עד ראש צוות באמצעות לימודים וניסיון.
- אוכל, מצרכים, בישול, מנוחה, חברים, פארק וסטודיו אימונים.
- בנק עם חיסכון, הלוואות וריבית, תשלום שכירות ומעבר לדירה משודרגת.
- מחשב נייד, שיעורים מקוונים, פרילנס ועבודה מרחוק; אופניים ומשלוחים; הזמנת ארוחה הביתה.
- שני מסלולי מטרות, סיכום שבוע, אירועי סוף שבוע, יומן, שמירה מקומית וניצחון.
- ממשק משחק קומפקטי בעברית ו־RTL, לוח תחרות וארבע מטרות עם סמן כתום ליריב. בנייד יש חיצי מגע. תצוגה קלה זמינה למכשירים ללא WebGL; כשל תלת־ממד מוצג במפורש ואינו מוחק שמירה.

הסביבה היא תלת־ממד מסוגנן שנוצר בקוד, לא גרפיקה פוטוריאליסטית. נוספו שמיים מדורגים, תאורה חמה, השתקפויות סביבה, חספוס ומרקמי לבנים, ריצוף, אספלט ועץ, לצד מסגרות חלונות, ניקוז, מזגנים וסוכך קפה. אלה חומרים פרוצדורליים, לא צילומים או נכסי תלת־ממד שנרכשו. המכוניות והעוברים ברחוב הם תפאורה; אין כרגע נהיגה חופשית, מערכת קרב או דיבוב מקצועי.

### חדשות קופצות

בסיום השבוע מופיע מבזק **״שכונה 24״**, עם מגיש מהיצורים, כותרת, השפעה על כסף ואושר ומדד המחירים החדש. אירועי המשחק הקיימים נשמרו: הופעה, החזר כספי, סוף שבוע שקט, מפגש שכנים ותיקון בבית. ההשפעות מחושבות פעם אחת בסיכום השבוע, לא בפתיחת החלון. כפתור **״חדשות״** פותח ארכיון של 12 המבזקים האחרונים, הנשמר גם לאחר רענון. חשבונות השבוע זמינים מתחת למבזק.

### משחק רשת לשני שחקנים — בטא

בכתובת שמוגשת משרת Node בוחרים **״רשת״**, יוצרים חדר ושולחים לחבר את קוד שש הספרות/אותיות. החבר נכנס לאותה כתובת ומצטרף. שני השחקנים מתחילים במסלול הקצר עם אותם משאבים; אין ייבוא שמירות מקומיות לחדר.

- השרת מאמת את הפעולות ומחשב כסף, זמן, הזמנות קפה, התקדמות וניצחון; הדפדפן אינו שולח יתרות לקביעה.
- משחקים במקביל בתוך השבוע. הראשון שמסיים ממתין לשני; רק אז שניהם עוברים לשבוע הבא עם אותו אירוע ומדד מחירים. השלמת היעדים אצל שניהם באותו סיכום שבוע היא תיקו.
- לוח התחרות מציג התקדמות, זמינות ואת הפעולה האחרונה מהשרת, ומתעדכן בערך פעם בשנייה. אפשר לצפות בשחזור 80 הפעולות האחרונות של החבר. דמותו מופיעה ליד היעד האחרון המאושר, וגם במבנה משותף; זו **לא** העברת צעדי הליכה בזמן אמת.
- הפעולות הרגילות, שיחות והכנת קפה זמינות; משימות רכיבת משלוחים נשארות מקומיות ואינן זמינות בחדר.
- כל פעולה מאושרת נשמרת בשרת לפני תשובת הצלחה. בזמן תקלה אין המשך כלכלי מקומי חלופי. אם לא התקבל אישור לפעולה, בודקים את המצב לאחר חזרת החיבור לפני שמנסים שוב.
- מפתח החיבור נשמר ב־`sessionStorage`, ונשאר ברענון אותה לשונית; סגירתה או מחיקת נתוני האתר עלולות לאבד גישה למושב. אין חשבונות, החלפת שחקן או חיבור לפי קוד בלבד למושב שכבר תפוס. אין לשתף את מפתח החיבור.
- **״לחזור למשחק המקומי״** מחזיר לשמירה המקומית ללא שינוי בה. החדר ממשיך להתקיים עד 24 שעות מיצירתו; היציאה אינה מפנה מושב.

להפעלת שרת ברשת הביתית, על המחשב המארח:

```powershell
$env:HOST = "0.0.0.0"
$env:PORT = "4174"
npm start
```

החבר גולש לכתובת ה־IP של המארח בפורט 4174; נדרשת הרשאת חומת אש מתאימה. אין לפתוח פורטים ציבוריים באופן אוטומטי.

**פרסום רשת ציבורי דורש אירוח נוסף:** מריצים עותק יחיד של `node server.js` עם Node.js 22+, מתקינים תלויות באמצעות `npm ci --ignore-scripts`, ומגישים את האתר ואת `/api/rooms` באותו מקור דרך HTTPS ו־reverse proxy. מגדירים `HOST` ו־`PORT` לפי המארח. הספרייה `server-data` חייבת להיות מתמשכת, מוגנת ומגובה; היא אינה חלק מאתר Pages ואינה נכללת ב־Git. אחסון ארעי יאבד חדרים באתחול. אין להריץ כמה עותקי שרת על אותו קובץ. הגבלת הבקשות היא לפי כתובת החיבור, ולכן יש להביא בחשבון proxy משותף. הבטא אינה כוללת שידוך ציבורי, חשבונות או תשתית לעומס המוני.

### ביצוע פעולות בעולם

רוב הפעולות מפעילות סצנה של 4–5 שניות, בנוסף להליכה הקצרה לעמדה. מזיגת רכיב וניקוי כוס קצרים יותר. המצלמה מתקרבת, לוח הפעולות מפנה את המקום לסצנה, ומוצגים שלבי הביצוע. אפשר ללחוץ **״דלג על האנימציה״** או Escape כדי לחזור מיד לשליטה.

החוקים מחושבים וההתקדמות נשמרת פעם אחת, לפני האנימציה. דילוג, רענון או סגירת הדפדפן אינם מזכים שוב בשכר ואינם גובים שוב כסף או שעות. בזמן הסצנה לא ניתן לבצע פעולה נוספת. פעולה שנדחית בגלל כסף, זמן או אנרגיה אינה מפעילה סצנה. שגיאת שמירה עדיין מוצגת במפורש; במקרה כזה ההתקדמות נשארת בזיכרון בלבד.

הסצנות ממחישות את פעולות הסימולציה, ואינן הופכות כל כפתור למיני־משחק נפרד. את מתכון הקפה עדיין מרכיבים בעצמכם, כולל אנימציה לכל מזיגה והגשה; משלוח האופניים נשאר משימת רכיבה בשליטה מלאה. בתצוגה הקלה הפעולות נשארות מיידיות, ללא סצנות WebGL.

### היצורים בעיר

הקאסט כולל עשרה עיצובים בהשראת תמונת הייחוס: כחול פרוותי, ירוק בעל שלוש עיניים, סגול רך, זהוב עם עלים, ורוד עם עיני כוכב, טורקיז ארוך־צוואר עם שש עיניים, קיקלופ שמש, מנטה עם אוזניים נפולות, אצטרובל כתום ויצור כחול־לילה בעל ארבע עיניים.

נוספו ארבעה יצורים מקוריים: **ניצי**, גור שביט בגוני מנטה וסגול שהוא הדמות שלך; **להבון**, דמות הלהבה של דני; **שביב**, יצור מכונף עם זנב מאיר; ו**פטרי**, תושב עם כובע פטרייה. לחיצה על **״הכירו את היצורים״** בכותרת העיר פותחת גלריה עם השמות, המאפיינים ומקומות המפגש.

המודלים הם תלת־ממד מסוגנן שנבנה בקוד, לא סריקה או העתק מדויק של התמונה. לכל עיצוב צללית, תוספות וסידור עיניים משלו. היצורים הולכים, ממצמצים, מדברים ומבצעים את הפעילויות הקיימות. אותו מודל משמש ברחוב, בחללים, בפעילויות וברחוב המשלוחים; הדיוקנאות והדמות בתצוגה הקלה מותאמים לאותו קאסט. פרווה וקוצים מרובים משתמשים במופעים משותפים כדי לצמצם קריאות ציור.

שמות נותני השירות, הדיאלוגים, החוקים והשמירות הקיימות נשארו ללא שינוי. המראה החדש מופיע גם בשמירה ישנה, בלי להתחיל מחדש. תמונת הייחוס עצמה אינה מצורפת לאתר.

## חוקי הגרסה הזאת

מתחילים עם 1,400 ₪, שתי מנות מצרכים, דירת התחלה ו־60 שעות לשבוע. הליכה חופשית בעיר אינה גובה זמן: בכניסה ליעד אחר נגבות שעות לפי הדרך הקצרה במסלול הכלכלי המקורי; אופניים מקצרים אותה. זמן הנסיעה מופיע בריחוף על יעד במפה. יציאה לרחוב וכניסה חוזרת לאותו עסק אינן נסיעה. פעולות מציגות זמן, מחיר ותנאי פתיחה.

כל ארבעת יעדי המסלול צריכים להיות מלאים **באותו זמן**:

| יעד | בקצב שלי | החיים בגדול |
| --- | --- | --- |
| הון: מזומן + חיסכון − חובות | 6,000 ₪ | 12,000 ₪ |
| אושר | 75 | 85 |
| תעודות | 3 | 6 |
| דרגת קריירה | 3 | 4 |

ארבעה שיעורים, בקמפוס או אונליין, מעניקים תעודה. משרות:

| תפקיד | מקום | שכר לשעה | תעודות | שעות ניסיון |
| --- | --- | --- | --- | --- |
| בריסטה | קפה פינה | 45 ₪ | 0 | 0 |
| רכז/ת תפעול | מרחב עבודה | 80 ₪ | 1 | 12 |
| מפתח/ת תוכנה | פיקסל טק | 130 ₪ | 3 | 36 |
| ראש צוות | פיקסל טק | 180 ₪ | 5 | 90 |

משמרת אורכת שש שעות. גם משלוחים ופרילנס מוסיפים ניסיון. עבודה ולימודים דורשים לפחות 15 שובע ומספיק אנרגיה להישאר עם 5 לפחות. כל שעת פעולה או נסיעה צורכת שובע. מנוחה בבית וטיול בפארק מאפשרים התאוששות ללא כסף.

גם במצוקה אפשר להתאושש: כשמדד השובע נמוך מ־15, ארוחה קהילתית בפארק מעניקה 35 שובע ללא תשלום תמורת שלוש שעות. כך אפשר לחזור לעבוד גם אחרי שמסגרת ההלוואה נוצלה.

בסוף השבוע:

1. מתווספת ריבית של 1% לחיסכון (עיגול מטה) ו־2% לחוב (עיגול מעלה).
2. שכירות של 450 ₪, או 700 ₪ בדירה משודרגת, נגבית מהמזומן ואז מהחיסכון. חוסר הופך לחוב ומוריד 10 אושר.
3. האושר יורד ב־3; דירה משודרגת מוסיפה 6 אושר.
4. מנה מהתיק משמשת לארוחות ומעלה שובע ב־35. בלי מצרכים, השובע יורד ב־15 והאושר ב־5.
5. האנרגיה עולה ב־45, מתרחש אירוע ומתחיל שבוע עם 60 שעות. שעות לא מנוצלות לא נצברות.
6. מחירי הקניות והפעילויות הרלוונטיות משתנים בטווח 90%–110%; שכר, שכירות ותעריפי עבודה וקורסים מרחוק קבועים.

המחשב פותח שיעורים אונליין, פרילנס משתי תעודות ועבודה מרחוק למועסקים בתוכנה. אופניים פותחים משלוחים בפארק. הלוואה אינה מקדמת את יעד ההון. ציוד אינו נספר בשווי ההון.

אין מגבלת שבועות או פשיטת רגל. במשחק חדש התחרות מול דני מסומנת כברירת מחדל, ואפשר לבטל אותה למסלול חופשי. דני מתחיל עם אותם משאבים ומשחק שבוע אחרי השבוע שלך. הוא נוסע, מתקבל לעבודה, עובד, לומד, קונה אוכל ונח באמצעות אותן פונקציות ואותם מחירים. אין הכנסות חינם או הגבלת התקדמות של 95%. האירוע השבועי שלו קבוע (סוף שבוע שקט, מחירי בסיס), כדי שאפשר יהיה לשחזר ולבדוק את התור.

הראשון שמשלים את כל המטרות מנצח. ניצחון שלך עוצר את המרוץ בלי לתת לדני תור נוסף; אם דני מסיים ראשון, מתקבל מסך הפסד ולא ניתן להמשיך בפעולות כלכליות. השמירה כוללת את מצבו ואת רשימת פעולות השבוע האחרון. הצפייה היא שחזור של התור המחושב, לא שידור של שחקן אנושי; סגירה, צפייה חוזרת או רענון אינם מפעילים שוב את התור.

## שמירה ופרטיות

### הדמויות ומכונת הקפה

בכל מקום מחכה דמות: גילה, ניסו, ד״ר פלפל, תיקי, באגי, שקלר, סימה, זיק, מוטי ורוני. מתקרבים ולוחצים E, או בוחרים ״שיחה״ בלוח המקום. שלוש תשובות מציגות מראש זמן, מחיר והשפעות. בוחרים פעם אחת לכל דמות בכל שבוע; התגובה והמפגשים נשמרים. מספר המפגשים הוא זיכרון חברתי, לא תנאי קידום.

לאחר קבלה כבריסטה, הפעולה **״מאחורי מכונת הקפה״** פותחת הזמנה אינטראקטיבית. בתחילתה משקיעים 3 שעות ו־12 אנרגיה, וצריך לפחות 15 שובע. מוסיפים רכיבים לפי הסדר במתכון, עד ארבעה בכוס. אפשר לרוקן ולנסות שוב ללא קנס או שעון עצר. הגשה נכונה מעניקה 165 ₪ (90 בסיס ו־75 טיפ), 3 שעות ניסיון ו־5 אושר. הגשה שגויה מעניקה 90 ₪ ו־3 שעות ניסיון, ומורידה 2 אושר. המשמרת הרגילה נשארה ללא שינוי.

ההזמנה, כולל הרכיבים שכבר נוספו, נשמרת אוטומטית. צריך להגיש אותה לפני יציאה או סיום השבוע; אפשר להגיש אפילו כוס ריקה כדי לסיים. אחרי רענון חוזרים ישירות להזמנה. ארבעה מתכונים מתחלפים לפי מספר ההזמנות שהוגשו.

### תאימות לשמירות קודמות

רחוב המשלוחים הוא שכונה מקורית בתלת־ממד: המודול והספרייה נטענים רק בכניסה למשמרת, מאותו אתר וללא CDN. בדפדפן ללא WebGL נשמרת תצוגת הרכיבה הקלה עם אותם חוקים.

**משלוח אופניים:** לאחר שקונים אופניים ב״עדכני״, נכנסים לפארק השקמה ובוחרים ״לקבל משלוח״. קבלת ההזמנה משקיעה 3 שעות משחק ו־22 אנרגיה ומפעילה שעון של 60 שניות אמיתיות. רוכבים במבט מאחורי הרוכב באמצעות החיצים, WASD או כפתורי מגע. במחוז הגפן עוברים ליד כיכר השעון, שוק ומעבר חצייה. ליד בית הקפה בולמים (↓ או S) ולוחצים E או ״לאסוף״; ליד הלקוח עוצרים ובוחרים ״למסור״. רכיבה דרך הסמן בלבד לא משלימה הזמנה. מסירה בזמן מעניקה 220 ₪ ו־3 שעות ניסיון; ביטול או איחור אינם מזכים בשכר. המיקום ומועד הסיום נשמרים — רענון אינו מאפס את השעון. לנסיעת ניסיון בלי לגעת בשמירה, פותחים את המשחק עם `?ride-demo`.

שמירות קיימות נטענות ללא איפוס הכסף, העבודה או ההתקדמות. לשמירות מהגרסה הראשונה מתווספים אוטומטית שדות המפגשים וההזמנה, בלי לדרוש משחק חדש.

שמירה ישנה עם מדד דני פעיל מקבלת יריב אמיתי חדש עם משאבי פתיחה, בלי שינוי במצב השחקן. שמירה ללא דני נשארת חופשית; למרוץ שווה ממשאבי פתיחה זהים, בוחרים משחק חדש. רענון מחזיר לרחוב ליד המקום האחרון (או להזמנת קפה/משלוח פעילים); מיקום צעדים מדויק וסיבוב מצלמה אינם נשמרים. תור היריב האחרון נשאר זמין לצפייה מלוח התחרות.

במצב המקומי המשחק נשמר אוטומטית אחרי כל מעבר ופעולה ב־`localStorage` של הדפדפן, ללא חשבון, אנליטיקה או שירות חיצוני. שמירה תקפה רק באותו דפדפן ובאותה כתובת ופורט; מחיקת נתוני האתר מוחקת גם אותה. התחלת סיפור חדש מחליפה אותה אחרי אישור בטופס. שגיאות שמירה מוצגות למשתמש ולא מוסתרות. בזמן תקלה המשחק המקומי ממשיך בזיכרון בלבד. במצב רשת הפעולות וההתקדמות נשלחות לשרת המארח, ונחשפות ליריב שבחדר; פרטי החיבור אינם נשלחים ליריב.

## מה למדנו מהמקור

לפי המקורות שלהלן, Jones בנוי כמסלול של עסקים; כל תור הוא שבוע, וגם מעבר וגם פעולות עולים זמן. ארבע מטרות של עושר, אושר, השכלה וקריירה מניעות את ההתקדמות. לימודים פותחים משרות, הכסף מממן את ההוצאות ואת השיפור ברמת החיים, ויש אירועי סוף שבוע וכלכלה משתנה. כניסה לעסק מציגה את נותן השירות ואת אפשרויות הפעולה.

את מבנה השבועות והכלכלה שמרנו. 60 השעות, המחירים בשקלים, דרישות התפקידים, היריב והאיזון הם **בחירות עיצוב של הגרסה החדשה**, לא שחזור מדויק של חוקי המקור. משחק הרשת החדש הוא בטא לשניים; מניות, גנבות, וידאו ומוזיקה לא נכללים כרגע.

מקורות שנבדקו:

- [ScummVM: Jones in the Fast Lane](https://wiki.scummvm.org/index.php?title=Jones_in_the_Fast_Lane) — מבנה התורות, ארבע המטרות, המנוע והשחרור הראשון ב־1991.
- [Wikipedia: Gameplay](https://en.wikipedia.org/wiki/Jones_in_the_Fast_Lane#Gameplay) — מסלול, ניהול זמן, משרות, לימודים, אירועי סוף שבוע וכלכלה.
